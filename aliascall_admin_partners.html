월 정산

전달 1일~말일 결제분을 정산합니다. 매달 15일 지급 전에 (예: 11월 1~14일 사이) 지난달을 골라 [정산하기]를 누르세요. 부름 결제도 함께 받아 옵니다. 다시 눌러도 괜찮습니다 — 지급 완료로 표시한 건은 그대로 두고, 나머지는 그사이 환불을 빼고 다시 계산합니다.

새 공지 쓰기

수수료율 변경 · 지급 정지는 시행일 30일 전에 올리고, "중요"에 체크하세요. 중요 공지는 대리점이 [확인했습니다]를 눌러야 닫힙니다.

설정

⚠ 수수료율을 바꾸기 전에 반드시 30일 전 공지를 먼저 올리세요. 바뀐 비율은 저장한 뒤 결제분부터 적용됩니다.

가입 후 코드 입력 기간을 바꾸면 부름 쪽도 같게 바꿔야 합니다(부름 Supabase SQL Editor에서: update partner_settings set link_days = 30; — 숫자만 바꿔서).

🔑 부름 ↔ 에일리어스콜 연결 열쇠 만들기 (처음 한 번)

정산할 때 에일리어스콜이 부름 결제 목록을 받아 오려면 두 곳에 똑같은 비밀 열쇠가 있어야 합니다. 아래 단추를 누르면 이 컴퓨터에서만 새 열쇠를 만듭니다(어디에도 저장 · 전송되지 않음). 복사해서 두 Supabase의 Edge Functions → Secrets에 이름 PARTNER_SYNC_KEY 로 붙여 넣으세요. 이 열쇠는 채팅 · 메일로 보내지 마세요.
